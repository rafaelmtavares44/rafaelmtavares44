## 📂 Projetos em Destaque

### 🌿 [SHINA — Sistema Hidropônico AI-Native com MCP](https://github.com/rafaelmtavares44/shina-mcp)

> 🏆 *Artigo aceito no SBCUP 2026*

Plataforma completa que une **IoT + IA generativa** para monitorar hidroponia em tempo real. A estufa é exposta como ferramenta universal via **Model Context Protocol (MCP)**, permitindo que agentes de IA (Claude, Gemini, GPT) consultem sensores e operem o sistema em linguagem natural — sem alucinação, lendo dados reais via RAG.

**Stack:** ESP32 · Python · FastAPI · Redis · Node.js · Google Gemini · MCP · Docker
**Camadas:** Firmware C++ → Backend Python → Pipeline RAG → Servidor MCP → Dashboard
